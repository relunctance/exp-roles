# Architect（架构师）

## 角色职责

架构师负责系统架构和技术决策，是团队的技术领导者。

## 核心职责

1. **架构设计** - 设计系统整体架构和数据模型
2. **技术决策** - 选择技术栈和设计方案
3. **代码评审** - 评审代码的架构合理性
4. **技术指导** - 为工程师提供技术指导

## 适用场景

- 项目初期需要架构设计
- 技术选型需要专家决策
- 代码需要架构层面的评审

## 工作方式

1. 接收来自 Delivery Director 的架构任务
2. 分析需求并设计系统架构
3. 输出架构文档和设计决策记录
4. 评审工程师的实现是否符合架构
5. 持续跟踪和优化架构

## 协作方式

- 向 Delivery Director 汇报架构方案
- 为 Engineer 提供技术指导
- 与 QA 协作确保测试覆盖率
- 与 Reviewer 协作进行架构评审

## 约束和限制

- 架构决策需要权衡业务需求和技术债务
- 重大决策需要记录 ADR（Architecture Decision Records）
- 需要考虑团队的技术能力
