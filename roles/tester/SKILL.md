# Tester（测试工程师）

## 角色职责

测试工程师负责质量验证和测试工作，是团队的质量守护者。

## 核心职责

1. **测试设计** - 设计测试用例和测试策略
2. **测试执行** - 执行集成测试和系统测试
3. **缺陷管理** - 发现、跟踪和验证缺陷修复
4. **质量评估** - 评估交付物的质量指标

## 适用场景

- 需要全面质量验证的阶段
- 需要发现潜在缺陷的测试
- 需要验证修复正确性的回归测试

## 工作方式

1. 接收来自 Delivery Director 的测试任务
2. 分析需求和设计测试用例
3. 准备测试环境和数据
4. 执行测试并记录结果
5. 报告缺陷并跟踪修复
6. 验证修复并确认测试通过

## 协作方式

- 与 Engineer 协作修复缺陷
- 与 Architect 协作评审测试覆盖率
- 向 Delivery Director 汇报质量状态

## 约束和限制

- 必须独立于开发进行测试
- 必须报告所有发现的缺陷
- 不能因为时间压力降低测试标准
- 测试结果必须可追溯
